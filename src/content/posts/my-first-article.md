这是这个博客的第一篇文章。

在信息流、短视频和无数个“稍后阅读”之间，我终于决定搭一个属于自己的小角落。它不吵，不追热点，也不一定每天更新，但这里会放一些我愿意认真写下来、也愿意被未来的自己重新读到的内容。

## 为什么还要写博客？

因为有些想法，如果不写下来，就会像没发生过一样消失。

过去我很多次想记录点什么：一个折腾了很久才解决的问题、一本读完很有感触的书、一段突然冒出来的念头。但最后它们大多留在了备忘录、聊天记录，或者干脆留在了脑子里，然后被忘记。

博客对我来说，是一个更安静、更长期的地方。它不像社交平台那样急着被点赞，也不像聊天窗口那样转瞬即逝。它更像一张书桌：写下来的东西会留在这里，等我以后回来翻看。

## 为什么是静态博客？

因为我想要一个简单、快速、可控的地方。

静态博客没有复杂的数据库，页面提前生成，加载快，维护成本低。用 Markdown 写文章，用 Git 管理修改，托管在 [GitHub Pages / Vercel / Netlify / Cloudflare Pages]，几乎不需要操心服务器。

它可能不是最“强大”的方案，但对我来说刚刚好：**把注意力留给写作，而不是折腾系统。**

当然，折腾本身也挺好玩。这个博客用的是 [Hugo / Astro / Hexo / Jekyll / 其他]，主题是 [主题名]，以后也许还会慢慢改。

## 这里会写什么？

目前想到的是：

- 技术折腾与踩坑记录
- 阅读、电影和播客笔记
- 一些生活随想
- 项目进展和学到的东西
- 偶尔可能出现的无用但有趣的内容

没有严格定位，也不打算把自己限制在某个垂直领域。唯一的原则是：**尽量真诚，尽量有用，至少对未来的我有用。**

## 关于更新

我不承诺日更，也不承诺周更。

但我承诺：每次写，都尽量把它写完、写好。比起“稳定输出”，我更希望这里是一个能长期存在的地方。
